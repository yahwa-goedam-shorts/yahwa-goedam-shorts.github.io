개인정보처리방침 (Privacy Policy)

1. 앱 소개

「괴담쇼츠 업로더」(이하 "앱")는 유튜브 채널 「야화의 괴담」 운영자가 자신의 채널에 직접 만든 쇼츠 영상을 올리기 위해 개인적으로 사용하는 업로드 도구입니다. 일반 사용자에게 제공되는 서비스가 아닙니다.

2. 사용하는 정보

  • Google 계정 인증 시 부여되는 YouTube 업로드 권한(https://www.googleapis.com/auth/youtube.upload)만 사용합니다.
  • 이 권한은 운영자 본인의 채널에 동영상을 업로드하는 용도로만 사용하며, 다른 사람의 계정이나 데이터에는 접근하지 않습니다.
  • 앱은 이름, 이메일, 시청 기록, 구독 정보 등 개인정보를 수집하지 않습니다.

3. 저장 및 보관

인증 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 운영자는 언제든지 Google 계정 설정(myaccount.google.com/permissions)에서 앱의 접근 권한을 취소할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 또한 앱은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.
